# 05_CONTENT_ROADMAP — 恐竜ロースター・グラフィック・展示・掘りの拡張（ドラフト / オーナー検討用）

> 04_STAGE_PLAN が「器の作り方」なのに対し、これは「中身を何年ぶん、どう配分するか」の計画。
> 目的: **有名恐竜を序盤で使い切って後半の章がしぼむ事態を、配分ルールで防ぐ。**
> あわせて、ロースターから逆算した「必要グラフィックの先読み」「展示の二層表現」
> 「掘る遊び自体の拡張供給」を決める。

## 1. スター配分のルール

恐竜の知名度を3層で管理する（供給量の分析は前回のとおり: 層1≈15〜20種、層2≈50〜80種）。

- **層1（表紙級スター）は1章に1〜2体まで。** 前借り禁止。第1章でティラノ・トリケラ・スピノと
  3枚使ったのは「体験版のフック」として正解だが、以降はこのルールで守る
- 章の基本パック（4〜6種）= **スター1〜2 ＋ 準スター2〜3 ＋ びっくり枠1**
  - びっくり枠 = 「恐竜じゃない なかま」や たまご・生痕など、知名度ではなく**意外性**で立つ枠。
    スターの節約と学び（柱5）を同時に担う
- 各章に「**その章でしか会えないもの**」を必ず1つ（たまごの巣・琥珀・石板化石・全身骨格など）

## 4. 展示の二層表現 —「ホネのすがた」×「いきていたすがた」

復元のごほうびは**骨格**と**生体（いきていたら）**の両方を見せる。本物の博物館と同じ構成
（骨格標本＋復元画）で、学び（柱5）とも直結する。

- **復元の流れ**: 組み立て → 骨格が立ち上がる → 「▶ いきていたころ」ボタンで生体姿に変身
  （切替トグルはノート・博物館カードにも付ける。カードは 表=骨格/裏=生体 のフリップ）
- **生体ビューには「おおきさくらべ」**: 人のシルエットと並べる（子どもが一番喜ぶ定番）
- **アセット戦略 = 自前SVGイラスト路線（推奨）**:
  - 外部アセットはライセンス（CC0縛り）とプロキシ制限で入手が難しい。**骨格・生体とも
    統一タッチの自作SVG**にすれば、権利問題ゼロ・追加は章ごとに8〜12枚・スタイルが揃う
  - まず**スピノサウルス1種で骨格SVG＋生体SVGを試作**し、品質ラインをオーナーが判定（POC）
  - 3D生体モデルは「目玉種だけ」の将来オプションに格下げ。全種3D前提にはしない（04 §4）

## 5. 「掘る」単調さへの供給計画 — 4本の軸から章ごとに引く

掘る作業は放っておくと単調になる。**毎章かならず「新しい掘り」を1つ以上**入れるため、
発想の引き出しを4軸で管理し、章に割り当てておく。

- **軸1 場のルールが変わる（環境）**: 物理前提が変わるので一番効く
  - 水がしみ出す層（ポンプで抜く）／**壁面発掘**（崖を横から掘る=重力の向きが変わる）／
    凍土（とかしてから掘る）／流れ砂
- **軸2 骨側のルールが変わる（対象）**:
  - 大物の支え計画／微細骨の群れ（乱暴に掘ると消える）／たまごの巣（割らずに周囲だけ）／
    よろい小板ぜんぶ回収／石板化石（板を割らないよう縁から）
- **軸3 道具と測量が増える（手段）**: 道具Lvは5〜6段で頭打ちにし、**種類**で広げる
  - 👂きく→たんちき（範囲がうっすら見える）／ふるい（すな層の小物）／ライト／ポンプ
- **軸4 頭を使う（判断・知識）**: 学び=攻略（柱5）の本丸
  - 交差ボーンベッドの🔍判別／もろい層の順番パズル／**「この層にこの骨はおかしい」イベント**
    （時代の知識で違和感に気づくとレア発見につながる）
