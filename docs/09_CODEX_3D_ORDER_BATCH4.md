## 2. 翼竜の共通仕様（第4弾の追加ルール）

1. **飛行ポーズで浮かせる**（ケツァルコアトルスを除く。§3-2参照）。
   つばさを ひろげた滑空姿勢。**体の最下点を y ≈ 翼開長×0.08** 浮かせる
   （博物館の天井吊り展示のイメージ。カメラは自動フィットする）
2. **つばさの骨格は「うで + ながい くすりゆび1本」**。骨格ビューで
   上腕→前腕→ながい第4指の節が読めること（ゲーム内の学び
   「つばさは ながーい ゆび」と直結する、本弾の学びの本丸）
3. **皮膜（まく）は軟組織**: 生体ビューにだけ張る。骨格ビューでは消え、
   指の骨だけが残る（生体⇄骨格の切替で「まくが きえる」驚きを作る）
4. 翼はZ方向（左右）へ広げる。原点=体の中心の真下、顔は +X（06 §4と同じ）
5. 頭部は 07 §3 の顔ルール（大きな目・虹彩・こわくしない）

## 3. 種別モデルシート

### 3-1. プテラノドン（翼開長7m・飛行ポーズ）

| 項目 | 指定 |
| --- | --- |
| ポーズ | **滑空**。つばさを まっすぐ左右へ。頭はわずかに下げ、あしは後ろへ |
| あたま | **うしろへ ながく のびた とさか**（最重要シルエット）。ハの ない くちばし |
| つばさ | まく は うでから あし の つけね まで。生体のみ |
| 尾 | ほぼ 無し（みじかい） |

- 真横チェック: 頭が右／とさかと くちばしが 一直線ぎみ／尾が ほぼ無い
- 骨格の読みどころ: とさか つきの頭骨・**ながい第4指**・うすい むねの りゅうこつ
- 初期カラー: 背 `#B98A5A` ／ まく `#D9A441` ／ 腹 `#EFE6C8` ／ とさか先 `#C0563E`

### 3-2. ケツァルコアトルス（翼開長10m・地上ポーズ）

| 項目 | 指定 |
| --- | --- |
| ポーズ | **地上で 4ほんあし**（つばさを たたんで 前あしに）。**キリンのように 頭を高く**。
  飛行ポーズには しない（プテラノドンとの見分け＝立ち姿。全高 約4.5〜5m） |
| あたま | ハの ない ながい くちばし。とさかは ひかえめ |
| くび | **ながく まっすぐ**（本種の見せ場。りくを あるく巨人） |
| つばさ | たたんだ第4指が うでの よこに そって 上へ折りたたまれる |

- 真横チェック: 頭が右上／肩より頭が ずっと高い／たたんだ ゆびの骨が読める
- 骨格の読みどころ: ながい くびの椎骨・たたまれた第4指・すかすかの軽い骨
- 初期カラー: 体 `#C7B08A` ／ くび・頭 `#E8D9B0` ／ くちばし `#B08050` ／ まく `#A98F6B`

### 3-3. ランフォリンクス（翼開長1.8m・飛行ポーズ）

| 項目 | 指定 |
| --- | --- |
| ポーズ | 滑空。実寸 1.8m で作る（カメラが寄る） |
| 尾 | **ながい しっぽ + 先の ひしがたの かじ**（最重要。あたらしい翼竜との見分け） |
| あたま | まえに とびだした ハ（すこしだけ・こわくしない）。とさかは 無し |

- 真横チェック: 頭が右／しっぽが 翼開長の半分ほど ながい／ひしがたの かじ
- 骨格の読みどころ: ながい尾椎の列・第4指・とがった あご
- 初期カラー: 背 `#8A6E4E` ／ まく `#C77A5A` ／ 腹 `#EFE0C0` ／ かじ `#C0563E`

### 3-4. カルノタウルス（全長8m・二足）

翼竜ではない（がけの ぬしの 隠し種）。ティラノ・アロと同系の水平二足で立たせる。

| 項目 | 指定 |
| --- | --- |
| あたま | みじかく 高い頭骨 + **めの上の ウシのような ツノ 1対**(最重要) |
| うで | **ティラノより さらに小さい**。ゆびは ほぼ 読めない程度でよい |
| あし | ながく 引きしまった後肢（スプリンター。ティラノより 脚長に見せる） |
| 肌 | 生体は こまかい うろこ の印象（ポリゴンで彫らず、色ムラ程度でよい） |

- 真横チェック: 頭が右／全長:全高 ≈ 3:1／ツノが シルエットで読める／腕が 極小
- 骨格の読みどころ: **ツノつき頭骨・極小の腕・ながい後肢**（ティラノ・アロとの3すくみ）
- 初期カラー: 体 `#7A4A3A` ／ 腹 `#E8D5B0` ／ ツノ `#F2EAD8` ／ 虹彩 `#C68B38`
