## 2. 海生種の共通仕様（第3弾の追加ルール）

1. **遊泳ポーズで浮かせる。** 海の生きものは足で立たない。骨格・生体とも
   **同じゆるやかな遊泳ポーズ**（体軸ほぼ水平、尾をわずかにうねらせる程度）で、
   **体の最下点を y ≈ 全長×0.06** だけ地面(y=0)から浮かせる
   （博物館の「吊り展示」風。展示側のカメラはバウンディングボックスに自動フィットする）
2. 原点 = 体の中心の真下の台面。顔は +X（06 §4 と同じ）
3. ひれ（パドル）は **指の骨が中に通っている**。骨格ビューでは
   ひれの中の指骨の列が読めること（「あしが ひれに しんかした」が学びの本丸）
4. 回して見たときの背中側・腹側の配色境界をはっきり（カウンターシェーディング）
5. こわい顔にしない・歯は最小限（07 §3 と同じ）

## 3. 種別モデルシート

### 3-1. モササウルス（15m・海のトカゲ）

| 項目 | 指定 |
| --- | --- |
| 体型 | **ながい流線形のトカゲ体型**。首はほぼ無く、頭から胴がなめらかに続く |
| あたま | ワニより幅のある長い口。**円すい歯をずらり**（閉じ気味） |
| ひれ | **4まいのパドル**（前が大きめ）。骨格では中の5指の骨列を見せる |
| 尾 | **先が下に折れ、上に尾びれの葉**（サメを上下逆にした形）。縦に平たい |

- 真横チェック: 頭が右／全長:全高 ≈ 5:1 の細長さ／尾先の下折れが読める
- 骨格の読みどころ: 長いあごと歯・パドル内の指骨・**下に折れた尾椎**
- 初期カラー: 背 `#3E6E7E` ／ 腹 `#EDE6CB` ／ 尾びれ `#2E5260` ／ 虹彩 `#C6A538`

### 3-2. プレシオサウルス（3.5m・くびながりゅう）

| 項目 | 指定 |
| --- | --- |
| 体型 | **たる型の胴 + ながい首 + 小さな頭**。首は前方へゆるく S字（垂直に立てない） |
| ひれ | **同じ形の大きなパドル4まい**（本種最大の見せ場。前後ほぼ同大） |
| 尾 | みじかい。ひれより目立たせない |
| あたま | 小さく、目は大きく愛嬌 |

- 真横チェック: 頭が右／首の長さ ≈ 胴とほぼ同じ／4まいのひれが同形と分かる
- 骨格の読みどころ: **数珠のような首椎の列**・4まいのパドル内の指骨・広い腹の肋骨かご
- 初期カラー: 背 `#5B7FA6` ／ 腹 `#EFE8CC` ／ ひれ先 `#41618A` ／ 虹彩 `#3E5C40`

### 3-3. アーケロン（4m・巨大ウミガメ）

| 項目 | 指定 |
| --- | --- |
| こうら | **ドーム低めの巨大な甲羅**。生体はなめらかな革ばり（オサガメ風の縦うね数本）。
  **骨格ビューでは骨の「わくぐみ」**（すきまのある骨組み＝本種最大の見せ場） |
| ひれ | 翼のように広げた**大きな前びれ**（後びれは小さめ） |
| あたま | カギ形のくちばし。目は大きく |
| ポーズ | はばたき遊泳の途中（前びれをやや下げた滑空姿勢） |

- 真横チェック: 頭が右／甲羅の高さ ≈ 全長の1/4 の低いドーム／前びれが甲羅より長い
- 骨格の読みどころ: **すきまのある甲羅の骨組み**・ひれの中の長い指骨・くちばし
- 初期カラー: 甲羅 `#6E5A43` ／ 体 `#8A9B7E` ／ 腹 `#EFE6C8` ／ くちばし `#D9C9A0`

### 3-4. ベレムナイト（0.5m・特例仕様）

アンモナイト（07 §4-3）と同じ「化石⇄生体」方式。

| 項目 | 指定 |
| --- | --- |
| 2ビューの意味 | **骨格ビュー＝ロストルム（つつ形のしん）の化石**。**生体ビュー＝イカ姿** |
| 生体 | イカ形の胴（後端がとがる）＋**腕10本**（先を丸く）＋ひれ2まい＋大きな目 |
| 化石（骨格ビュー） | 先のとがった円すい棒。骨色系。表面に成長線のすじを1〜2本 |

- 実寸 0.5m で作る（カメラはビューアー側で寄せる）
- 初期カラー: 生体 `#C77A5A`（背）/ `#EFDCC8`（腹）／ 化石 `#E8DCC4`

### 3-5. イクチオサウルス（3m・隠し種）

| 項目 | 指定 |
| --- | --- |
| 体型 | **イルカそっくりの流線形**。ただし**尾びれはタテ向き**（イルカはヨコ。ここが学び） |
| あたま | ほそながい くちばし状の口。**とても大きな目** |
| ひれ | 背びれ1・胸びれ2・腹びれ小2・**三日月形のタテ尾びれ** |
| 骨格の目玉 | **目の中の骨のリング（こうまくりん）**を骨格ビューで見せる。
  背びれは軟組織なので**骨格ビューでは消える**（生体との差分も学び） |

- 真横チェック: 頭が右／イルカ体型／尾びれが上下に開く（水平でない）
- 骨格の読みどころ: **目のリング**・魚のように密な背骨・下にカクッと折れる尾椎
- 初期カラー: 背 `#4A6B8A` ／ 腹 `#F0EAD2` ／ 目のまわり `#2E4A66` ／ 虹彩 `#C68B38`

## 4. 受け入れ基準（種ごと）

06 §7・07 §5 の共通チェックに加えて:

- [ ] 遊泳ポーズで浮いている（足で立っていない）。骨格・生体が同ポーズ
- [ ] ひれの中の指骨が骨格ビューで読める（ベレムナイトを除く）
- [ ] モササウルス⇄イクチオサウルスを並べて取り違えない
      （大きさ・尾の形・目のリングで区別できる）
- [ ] `?species=` セレクタから確認でき、1種1コミットで build / ESLint / Prettier が通る
