## 1. 発注概要

子ども向け（6〜10歳）ブラウザ3Dゲーム「ほねほり調査隊」の博物館展示に使う、
**恐竜の3Dモデル**を作ってほしい。1種につき2つの姿を用意する:

- **ホネのすがた**（骨格標本。博物館に立っている骨格）
- **いきていたすがた**（生体復元。肉と皮がついた姿）

これを**ぐるぐる回して色々なアングルから見られるビューアー**に載せ、
**ボタンひとつで骨格⇄生体を切り替え**られるようにする。本物の博物館の
「骨格標本＋復元画」の関係を、子どもが指で回して楽しめる形にするのが目的。

**まずはパイロット1種: スピノサウルス**（骨格＋生体＋ビューアー）を納品。
発注側がクオリティを確認してから、残りの種を同じ様式で追加発注する。

## 2. 納品物（パイロット）

1. `src/art/dino3d/spinosaurus.ts` — スピノサウルスの骨格・生体モデルを
   **Three.js のコードで手続き的に生成する** TypeScript モジュール（§4の契約に従う）
2. `src/art/dino3d/common.ts`（任意）— 種をまたいで使う共通ヘルパー
   （骨の基本形・マテリアル定数など。今後の量産の土台になるので推奨）
3. `poc/poc9/index.html` ＋ `poc/poc9/main.ts` — ビューアーページ（§5）
4. `poc/poc9/README.md` — 実装メモ（色や体型を調整するときにどの定数を
   触ればいいか、を発注側が分かるように）

**形式はコード生成（プロシージャル）を必須とする。** 外部の3Dファイル
（glb/fbx/obj等）やテクスチャ画像の同梱・ダウンロードは不可（§3の制約）。
コードなら差分レビュー・微調整・種の量産（ヘルパー共有）がしやすいため。

- three.js **r180**（`package.json` にある。バージョン変更・依存追加は不可）
- TypeScript **strict**（`noUncheckedIndexedAccess` 有効）・Vite 7 ビルド
- **新しい npm 依存を追加しない。CDN・外部URL・ネットワーク読込は一切不可**
- すべて**オリジナルの造形**であること。既存モデルの写し・映画等の実在IPを
  想起させる意匠は不可（科学的な恐竜の姿はOK）
- 対象機は **iPad Safari**。60fps を保てる軽さにする（§4のポリゴン予算）
- 既存ゲームコードは変更しない。触ってよいのは
  `src/art/dino3d/`（新規）・`poc/poc9/`（新規）・`vite.config.ts`
  （`poc9` の input 1行を追加するのみ）
- コミットは Conventional Commits（例: `feat(poc9): spinosaurus 3d viewer`）

## 4. 3Dモデル仕様

### 座標と規約（骨格・生体で共通）

- **1 unit = 1 m**。スピノサウルスは全長 約14m
- **原点 = 両足のあいだの地面**（y=0 が接地面）
- **顔は +X 方向**を向く
- 骨格と生体は**同じポーズ・ほぼ同じシルエット**にする
  （切り替えたとき「骨に肉がついた!」と分かることが最重要）
- 返す `THREE.Group` の scale は 1（呼び出し側で縮尺する）

### モジュール契約

```ts
// src/art/dino3d/spinosaurus.ts
import * as THREE from 'three';

export interface DinoViews {
  skeleton: THREE.Group; // ホネのすがた
  living: THREE.Group; // いきていたすがた
}

/** 同期関数。ローダー・async・外部リソース禁止 */
export function buildSpinosaurus(): DinoViews;
```

### 品質・性能予算（1つの姿あたり）

- 三角形数 **10,000 以下**（目安 5,000〜8,000）
- draw call **30 以下**（ジオメトリのマージや InstancedMesh を活用）
- マテリアルは `MeshStandardMaterial` を基本とする。生体は滑らかな法線と自然な粗さ、
  骨格は必要に応じてフラットな面を使い分ける（テクスチャ画像は必須ではない）
- `castShadow = true` を設定（受け側でライトを用意する）

### 造形の方向性（アートディレクション）

- 子どもが形を読み取りやすい簡潔さは保つが、**木製玩具風の板・棒・貼り付けた色面にはしない**。
  筋肉と骨格が連続する有機的なボリューム、滑らかな陰影、自然な皮膚色を優先する
- 優先順位は **種固有のシルエット → 骨格と生体の対応 → 子ども向けデフォルメ → 表面ディテール**。
  かわいさのために脚の役割や基本姿勢を別の動物へ変えない
- 生体: 目は大きめで愛嬌のある顔。怖くしない（子どもが夜思い出しても平気な顔）
- 骨格: 博物館の骨格標本らしく——頭骨・背骨の連なり・ろっ骨・四肢・
  **みわけポイントとなる骨**（下記）がはっきり読めること

### スピノサウルスの必須要素

| 部位 | 要件 |
| --- | --- |
| あたま | **ワニのように細長い口**（最重要のシルエット）。円すい形の歯 |
| せなかの帆 | **大きな帆**。骨格では背骨から伸びる長い棘（とっき）の列として表現 |
| 尾 | 縦に平たい「オール型」の尾 |
| 姿勢 | **後肢で体重を支える二足の獣脚類**。腕は地面につけず、短い3本指と爪が読めること |

生体の初期カラー案（調整可。README に定数として出すこと）:
体 `#4E8F7C` / 腹 `#F1E6C3` / 帆 `#E8865A`（帆に濃い縞 `#C9653F`）/
骨 `#F2EAD8`

## 5. ビューアー仕様（poc/poc9/）

- 博物館ホール風の落ち着いた背景（単色〜グラデで可。部屋のモデリングは不要。
  床の円形台座があると良い）
- **OrbitControls**: 1本指/ドラッグで回転・ピンチ/ホイールでズーム
  （damping有効・距離と俯角に制限・地面の下に潜らない）
- 操作しない時間が数秒続いたら**ゆっくり自動回転**（ターンテーブル展示）
- 切り替えUI: 画面下に大きなボタン2つ「🦴 ホネのすがた」「🦖 いきていたすがた」
  （**最小48px**・現在の状態が分かるハイライト）
- 切り替えは**その場でクロスフェード**等のなめらかな遷移（リロード・カメラ
  リセットをしない。回している最中に切り替えても視点が保たれること）
- ネームプレート表示: 「スピノサウルス」＋一言
  「🔍 せなかの おおきな ほ! スピノサウルスの しるし」
- ライティング: 環境光＋ディレクショナル1灯（影あり）程度のシンプル構成
- 文字はひらがな・カタカナ中心（このゲームの対象年齢ルール）

## 10. Claudeへの設計フィードバック（2026-08-25 オーナー確認済み）

### 初版で起きたこと

- 「4足寄りの低い姿勢」をそのまま造形の主軸にし、前肢を歩行脚として地面につけた
- 丸い胴体・同じ役割の4本脚・太い棒状の尾が組み合わさり、トカゲ／サンショウウオに見えた
- 帆・長い口・尾という記号はあったが、それらを外すと獣脚類の骨格として読めなかった
- 要求を満たす部品の有無を優先し、全身シルエットのレビューが後になった

### 今後の方針

1. **最初に真横のシルエットを確認する。** 帆などの種固有パーツを一度隠しても、獣脚類の
   頭・首・骨盤・後肢・尾のバランスが読めること
2. **デフォルメはキャラクター表現に限定する。** 大きな目、丸い面、短い爪、太めの足先、
   明快な色分けは歓迎。二足を四足にする、腕を脚にする等の骨格変更はしない
3. スピノサウルスは、細長く狭い吻・後退した鼻孔・短く強い後肢・地面につかない把持用の腕・
   不規則な背中の帆・上下に深く横に薄い長い尾を優先する
4. 科学的に議論中の要素は1案に断定せず、**子ども向け強／中間／科学復元寄り**の3案を
   画像で比較してから3D実装する
5. オーナー選択は「子ども向け強」だが、これは目の読みやすさや親しみやすい比率を指す。
   木製玩具風の質感・棒状の四肢・板状の色面は採用せず、動物として自然な立体を優先する
6. **選択後のコンセプト画像は雰囲気資料ではなくモデルシートとして扱う。** 今回は3案の左を
   正本とし、頭の向き、全長と全高の比、胴・頭・脚・尾・帆の相対寸法、配色境界を真横の
   初期表示で照合する。部品が揃ったことやポリゴン数の更新だけでは完成判定にしない
7. 初期表示は自動回転させず、UIが胴体や腕に重ならない状態で比較する。少なくとも
   **頭が右／横幅は全高のおよそ1.6倍／短い樽型の胴／太い二足／長い三角尾／幅広い台形の帆**
   が一目で一致してから、骨格表示や回転時の見栄えを詰める

この方針はスピノサウルス以降の全種にも適用する。リアルさを上げることが目的ではなく、
**デフォルメしても別の動物に見えないこと**が品質基準。
