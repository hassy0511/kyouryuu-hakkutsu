## 2. 本弾の考え方「ホネのすがた = 石板」「いきていたすがた = もとのすがた」

この5種は 恐竜のように ホネを組み立てるものではない。展示の2層は こう読み替える:

| ビュー | 5種での意味 |
| --- | --- |
| 🦴 ホネのすがた | **石板（化石そのもの）**。石の板に 浅い凹凸で 化石が 彫ってある。指で回して 見る |
| 🦖 いきていたすがた | **もとのすがた**。その化石が できる前の 生きもの／できごと（下表） |

ゲーム側の切替ボタン・カメラの自動フィット・ヒビ(★)のルールは そのまま使うので、
**両ビューとも 必ず 返す**こと（片方だけ にしない）。

### 石板の共通仕様

1. **置き方**: 台座に寝かせず、**化石面を カメラ側(+Z)に向けて 30〜40° 起こす**
   （後ろに もたれた 板。展示カメラは +Z 側から 見下ろす）。原点 = 板の接地点(y=0)。
   板の中心が x=0, z=0 付近
2. **彫り**: 化石は 板の面に **浅い凹凸として メッシュに 埋め込む**（板の上に 別メッシュを
   貼らない。表面ディテールパスの規約と同じ）。深さの目安 = 板の厚みの 1/4〜1/3
3. **板の形**: 四角すぎない。角が 欠けた 自然な 割れ口、厚み 4〜6cm、縁は 岩肌
4. 色: 石板 `#C9BFA6`（石灰岩）／ 化石の面 `#8A7A62`（濃い）／ 割れ口 `#B0A68E`
5. 予算: **1ビュー 4,000三角形以下・draw call 10以下**（小さな対象なので 厳しめ）。
   実寸（上表）で作る。カメラは 自動で 寄る（アンモナイト0.3m の 前例あり）
6. いきていたすがたの 生きもの（鳥・魚・赤ちゃん）は 07 §3 の 顔ルールを 引き継ぐ

## 3. 種別モデルシート

### 3-1. しそちょう（0.5m の 石板）
- 石板: **ベルリン標本の ポーズ** — 翼を ひろげ、首を うしろに そらし、ながい 尾。
  翼と 尾の まわりに **羽の あとが 放射状**に 彫られる（ここが 本種の 命）。歯と 手のツメが 見える
- いきていたすがた: **羽の生えた 小さな 鳥恐竜**（全長0.5m）。地面に 立ち、翼を 半分ひろげる。
  尾は ながく 羽つき。色: 羽 `#3E4A5A`（暗い青灰）／ 翼の縁 `#E8E0C8`／ くちばし・脚 `#C9A86A`
- 学び: 「ハも ツメも ある とり」— 恐竜と 鳥を つなぐ

### 3-2. いしばんの さかな（0.4m の 石板）
- 石板: 魚が **横向きに まるごと** — 背骨・肋骨・ヒレの 骨・尾ビレの 骨が 細かく 並ぶ
  （ゾルンホーフェン風の 石灰岩）。頭と 目の 穴が はっきり
- いきていたすがた: **泳ぐ 魚**（0.4m）。浮かせ展示（08 §2 の 海組と同じ。最下点 ≈ 全長×0.1）。
  色: 体 `#7FA8C9`／ 腹 `#E8F0F4`／ ヒレ `#5A7A9A`

### 3-3. きょだいな あしあと（0.9m の 石板）
- 石板: **3本指の 大きな 足あと 1つ**（獣脚類型・アロサウルス級。長さ 約55cm）が
  板の 中央に 深めに 凹む。指の先に ツメの 切れこみ。まわりに 乾いた 泥の ひび
- いきていたすがた: **足あとの ぬし の 足**（足首から下・3本指・ツメつき）を
  足あとに **ぴったり 重ねて** 置く。足は 半透明（opacity 0.5〜0.6）にして
  「だれが あるいたか」が 見える。板は そのまま 残す
- 学び: ホネじゃないのに 化石（生痕化石）

### 3-4. よろいの こばん（0.6m の 石板）
- 石板: 平らな 岩の 面に、**楕円ドームの 小板が 20〜30枚 散らばる**（大小まぜる・
  一部は 岩に 半分 うまる）。アンキロサウルスの 皮骨
- いきていたすがた: **小板が 並んで よろいに 組み上がった 皮ふの 一部**
  （背中の ひときれ。帯状に 並ぶ 骨板 + とげ 2〜3本、下は 皮ふの 面）。
  第5弾 アンキロサウルスの 背中と 色・形を 合わせる（体 `#8A7A56`／ 板 `#6E6248`）
- 学び: 「ぜんぶ あつめると よろいに なる」— 散らばり → 組み上がり を 2層で 見せる

### 3-5. たまごのす（0.5m の 石板）
- 石板: **卵の化石が まるく 並ぶ**（10〜12個・楕円・半分 岩に うまる）。
  卵の 表面は ざらつき。巣の 縁は 土の 盛り上がり
- いきていたすがた: **砂の 巣に 卵が 並び、1つだけ 孵化中**（殻が 割れて 赤ちゃんの
  頭が のぞく・目は 大きく 愛嬌）。卵の 色 `#E8DCC4`／ 巣の 砂 `#C9A86A`／ 赤ちゃん `#9AA86A`
- 学び: 恐竜も 子育てを した
