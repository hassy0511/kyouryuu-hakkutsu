## 0. 現状分析 — なぜ すぐ遊び終わるのか

現在の規模: 種4（骨13）・現場6・道具2段階・素材4種・島1。

1. **現場が浅い**: 平均2骨、8×8×6格子。ギミックが岩・支え・岩盤の3種しかなく、
   3〜4現場目で組合せが出尽くす
2. **進行がほぼ一本道**: 「見つけた順に掘る」だけ。道具ゲート（岩盤）が2か所しかなく、
   「戻ってくる楽しみ」が1回しか起きない
3. **収集の谷がない**: 素材もレシピも1周で満たせる。「足りないから探しに行く」が
   がんじょうピッケルの1回だけ
4. **リプレイ動機が★上げのみ**

→ 対策は「現場を深くする」「島の探索を本格化する」「島ごと増やせる器を作る」の3層。

## 2. ピットの型カタログ（L1）— 1現場=1テーマで組む

実装コストが小さい順。上5つは**既存システムの組合せだけ**で作れる。

| 型 | あそび | 新規実装 |
| --- | --- | --- |
| 完全埋没型 | 地表に手掛かりゼロ。👂きくで測量してから掘る場所を決める | なし |
| 交差ボーンベッド型 | 2個体の骨が絡んで埋まる。🔍みわけポイントの知識で「どっちの骨？」を判別 | ラベル微修正 |
| 岩盤二重型 | 岩盤の下にさらに深い岩盤。Lv2→Lv3 で三度おいしい現場 | なし（データ） |
| 支えパズル大物型 | 6〜8マスの大型骨。掘る順番を計画しないと必ず崩れる | なし（データ） |
| 大穴型 | 格子を 10×10×8 に拡張、複数個体＋全ギミック載せの「ボス現場」 | 格子サイズ可変化 |
| 湧き水型 | 掘ると水が染み出て溜まる。ポンプ（新道具）を作るまで下へ進めない | 新システム（中） |
| 流れ砂型 | 掘った隣から砂が流れ込む。いた（新アイテム）でせき止めて掘る | 新システム（中） |

新コレクション（骨以外）: **あしあと化石・うんち化石（コプロライト）・こはく**
→「生痕化石」＝体の化石じゃなくても暮らしがわかる、という学びネタ（柱5）。

## 3. 第2章「ジュラの島（仮）」の中身（L2＋L3）

開館式の手紙「となりの島で **くびの ながーい おおもの** が…」をここで回収する。

- **時代**: ジュラ紀（ノートの時代ページで「つぎの島には ジュラきの ちそうが…」と予告済み）
- **種（案・5〜6種）**:
  - ブラキオサウルス（くびなが＝手紙の答え・目玉）
  - ステゴサウルス ／ アロサウルス
  - 海エリアに **プレシオサウルス（くびながりゅう）** → 学びの目玉
    **「くびながりゅうは きょうりゅうじゃ ない!」**（海の爬虫類。はかせが解説）
  - 生痕化石 2〜3種（あしあと・こはく等）
- **規模**: 現場 10〜12（§2 の型を配置）、骨 20〜26、想定プレイ時間 第1章の 2〜3倍
- **島の構造（L2）**: 3エリア「みなと → もり → たきのうら」。エリア間にゲート:
  こわれた橋（🪵で修理）／くらい ほらあな（ランタンが要る）など、素材・道具で開く
- **道具**: **Lv3 くろがねのピッケル**（第1章クラフト画面の「？？？のピッケル」予告を回収）
  ＋新道具1（ポンプ or ランタン。湧き水型を入れるなら前者）
- **素材**: 新素材2種で「足りない→探す」の谷を作り直す
- **ストーリー**: となりの島の館長（はかせの旧友）から SOS →
  クライマックスは「ジュラのウィング」開館。第3章（さんじょうきの島）への引きを残す

## 4. データパック化（技術・L3の基盤）

- `src/data/islands/<id>/` に island.json（名前・エリア・ゲート・地形パラメータ）＋
  pits.json ＋ species.json ＋ story.json — **島の追加＝フォルダ追加**にする
- 種・時代・ちしきは共通プールに島ぶんをマージ（ノートは全島通算の1冊）
- **セーブ v2**: pits / discovered を島IDで名前空間化。v1セーブは
  「island=第1章」として自動移行（既存プレイヤーのデータは消さない）
- フィールド地形: 完全データ駆動は重いので **島ごとの地形関数＋配置はJSON** の折衷（推奨）
- 格子サイズ（8×8×6）を PitDef 単位で可変に（大穴型の準備）
- 性能予算は現行同等: ロードは常に1島ぶん。島間は⛵で移動＝シーン切替
