## 2. 本件のテーマ「ブラキオと 見分けられる くびなが」

くびなが（竜脚類）は これで **3種め**（ブラキオ23m・プラテオ8m・本種25m）。
子どもが 展示を ならべて 見たときに **とりちがえない** ことが 本件の合格ライン。

| | ブラキオサウルス | ディプロドクス |
| --- | --- | --- |
| 首の向き | **たかく ななめ上**（キリン型） | **ひくく 前へ 水平**（地面と ほぼ平行） |
| 高いところ | **肩**（前肢が長い） | **腰**（後肢が長い＝ブラキオと逆） |
| しっぽ | 太く みじかめ・下がり気味 | **細く ながい ムチ**。先は 糸のように 細る |
| ぜんたいの形 | 「へ」の字に せり上がる | **やじろべえ（シーソー）**。首と尾が 水平に つりあう |

- 真横チェック: **腰が最頂部**／首は ほぼ水平／**尾が 首より 長い**／頭は とても小さい
- プラテオサウルス（8m・後肢立ち）とも 並べて 混同しないこと（本種は 完全な四足）

## 3. モデルシート

| 項目 | 指定 |
| --- | --- |
| 姿勢 | **四足**。首は 前へ ほぼ水平、頭は 肩より すこし 低いくらい |
| 前後のバランス | **後肢が前肢より長く、腰が最頂部**（ブラキオと逆。ここを 逆にしない） |
| しっぽ | 全長の **半分ちかく**。根もとは太く、先へ 一気に 細って **ムチ**になる。 |
| | 先端は 地面から すこし 浮かせる（ひきずらない） |
| あたま | ごく小さい。**うまのような 細長い 顔**、鼻あなは 頭の上のほう。歯は 前のほうだけ |
| 首 | 細長い 首椎が ずらり。ブラキオより **細く・水平に** のばす |
| サイズ感 | 実寸25m。全高は 5〜6m程度（横に ながい シルエット） |

- 骨格の読みどころ: 水平に つらなる 首椎と 尾椎 ／ 尾の先の 細い骨の れつ ／
  小さな 頭骨 ／ 柱のような 四肢（後肢が やや長い）
- 生体で 追加するもの: 背すじの 小さな とげの列（歓迎・控えめに）・首と腹の 色の さかいめ
- 初期カラー: 体 `#8A7F62` ／ 腹 `#E3DCC0` ／ 背 `#6B6248` ／ 目の虹彩 `#3E4A3A`

## 4. ゲーム内の骨との対応（4本）

| 骨ID | 名前 | ゲーム内の説明 | モデルで 見えるべきもの |
| --- | --- | --- | --- |
| neck | くびのほね | ブラキオより ひくく のばした 細長い首 | 水平な 首椎の れつ |
| whiptail | むちのしっぽ | さきほど 細くなる ムチのような 尾 | **細る 尾の先**（本種の featureBone） |
| legs | あしのほね | **後肢のほうが 長い**（ブラキオと はんたい!） | 腰の高さ・後肢の長さ |
| spine | せぼね | 首と尾を ささえる やじろべえの しんぼう | 腰まわりの 太い 脊椎 |

## 5. 受け入れ基準

- [ ] ブラキオサウルスと 並べて **肩高／腰高・首の向き・尾の形**で はっきり 見分けられる
- [ ] 尾が 首より 長く、先が ムチのように 細る（featureBone が いちばん 目立つ）
- [ ] プラテオサウルス（後肢立ち）と 混同しない（本種は 四足で 頭が 低い）
- [ ] 三角形 1ビュー 10,000以下・draw call 30以下（実績の 3〜4k / 3〜9dc が 目安）
- [ ] `?species=diplodocus` で poc9 に 出る・`BUILDERS` 登録ずみ
- [ ] build / ESLint / Prettier が 通る（1種=1コミット）
