## 2. 本弾の共通テーマ「まもりの造形は骨」

とげ・よろい・板・ドームは **どれも骨（皮骨・骨質）**。ステゴの板と同じく、
**骨格ビューにも必ず残す**こと（消えるのは筋肉と皮ふだけ）。
生体⇄骨格の切替で「よろいは ほねだった!」が伝わるのが本弾の学びの本丸。

## 3. 種別モデルシート

### 3-1. アンキロサウルス（8m・四足）

| 項目 | 指定 |
| --- | --- |
| 体型 | **ひくく、はばひろい**（全幅は全高より広くてよい）。おなかは地面すれすれ |
| よろい | せなかに **よこ帯じょうの よろい列 + こばん（小さなとげ）の列**。かたに大きめのとげ |
| 尾 | さきに **おおきな ほねの こんぼう**（最重要シルエット）。尾はまっすぐ かたい |
| あたま | しかくく かたい頭。目の上・ほほに 小さなツノ |

- 真横チェック: 頭が右／全長:全高 ≈ 4:1 の低さ／こんぼうが 一目で読める
- 骨格の読みどころ: **こんぼう（融合した尾椎）・よろい帯を骨格にも残す**・はばひろい肋骨かご
- 初期カラー: 体 `#7A6A4A` ／ よろい `#5C4F38` ／ 腹 `#E8DCC0` ／ こんぼう `#F2EAD8`

### 3-2. スティラコサウルス（5.5m・四足）

| 項目 | 指定 |
| --- | --- |
| あたま | **フリルの ふちから ながい とげ 6ぽん**（放射状・最重要）+ **はなの上に ながいツノ1ぽん** |
| トリケラとの見分け | 目の上のツノは 無し（あっても ごく小さく）。フリルのとげが主役 |
| 体型 | トリケラより ひとまわり小さい がっしり四足。くちばし |

- 真横チェック: 頭が右／フリルのとげが シルエットで数えられる／鼻ヅノ1本
- 骨格の読みどころ: **とげつきフリルは頭骨と連続**・鼻ヅノ・くちばし
- 初期カラー: 体 `#8A9B5E` ／ フリル `#C0563E`＋とげ `#F2EAD8` ／ 腹 `#EBDFBB`

### 3-3. パキケファロサウルス（4.5m・二足）

| 項目 | 指定 |
| --- | --- |
| あたま | **まるく もりあがった ほねのドーム**（最重要）。ドームのふちに 小さなとげの かざり |
| 姿勢 | 水平姿勢の二足。首はみじかいS字、尾はまっすぐ |
| 体型 | ほっそり きみょうに 頭でっかち（こども頭身 歓迎） |

- 真横チェック: 頭が右／ドームの まるさが一目で読める／二足・尾水平
- 骨格の読みどころ: **分あつい ドーム断面の量感**（頭骨がほぼドーム）・とげの かざり
- 初期カラー: 体 `#A0785A` ／ ドーム `#E8D5B0` ／ とげ `#6E4A2E` ／ 腹 `#EFE6C8`

### 3-4. パラサウロロフス（10m・二足寄り）

| 項目 | 指定 |
| --- | --- |
| あたま | **うしろへ カーブして のびる くだ状のとさか**（最重要）+ カモのような ひらたい くちばし |
| 姿勢 | 後肢で立つ二足姿勢（イグアノドンと同じ考え方）。前肢は地面につけない |
| 尾 | たかさのある ひらたい尾。まっすぐ |

- 真横チェック: 頭が右／とさかが 頭の ながさの1.5倍ほど後ろへ／くちばしが ひらたい
- 骨格の読みどころ: **とさかは骨**（骨格ビューにも残す。可能なら つけねに 管の口を示唆）・
  すだれ状の腱で固い尾
- 初期カラー: 体 `#7E9B6A` ／ とさか `#C0563E` ／ 腹 `#EFE6C0` ／ 背の縞 `#5E7A50`
