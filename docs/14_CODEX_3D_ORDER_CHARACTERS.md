## 1. 発注のねらい

現在の主人公・はかせは カプセル+球の仮モデルで、歩きも「ぴょんぴょん跳ねる」
仮実装（オーナー指摘）。恐竜モデルと同じ品質の **キャラクターモデル** に差し替え、
**歩行/待機アニメーションもモデル側が持つ** 形にする。

## 2. 統合契約 — CharacterRig（最重要）

受け入れ側の口は **実装・配線済み**。`src/art/chars/index.ts` の契約に従い、
builder を納品して `BUILDERS` に1行登録するだけで、ゲーム内の仮モデルと
自動で差し替わる（恐竜レジストリと同方式）。

```ts
export interface CharacterRig {
  /** 足もとが原点(y=0=接地)・顔は +Z(進行方向)・scale 1 = 実寸(m) */
  group: THREE.Group;
  /** 毎フレーム呼ばれる。歩行サイクル・待機のゆれは この中で行う */
  update(dt: number, moving: boolean, speed: number): void;
}
export function buildPlayerCharacter(): CharacterRig; // src/art/chars/player.ts
export function buildHakaseCharacter(): CharacterRig; // src/art/chars/hakase.ts
```

- ゲーム側は 位置・向き(rotation.y)・接地(y) を管理する。update() 内で
  group 自体の position/rotation を動かさないこと（子パーツだけを動かす）
- **触ってよいファイル**: `src/art/chars/`（player.ts / hakase.ts 追加・index.ts 登録・
  共通ヘルパー追加可）と `poc/poc10/`（§5）、`vite.config.ts`（poc10 の input 1行のみ）

## 4. アニメーション仕様（発注の本丸）

**「ぴょんぴょん跳ねない、人の歩き」にすること。**

- 歩行（moving=true）:
  - 脚を 交互に ふる: 股ピボットで ±30〜35°、周波数は `speed / 歩幅(約0.5m) × π`
  - 腕は 脚と逆位相で ±15〜20°
  - からだの上下は **2cm以下**（脚の2倍の周波数）。ジャンプ・バウンドはしない
  - 進行方向へ 3〜6° まえかがみ。頭は ほぼ水平を保つ
- 待機（moving=false）:
  - こきゅうの ゆれ（肩・胸が ±1%程度）+ ときどき 頭が すこし かたむく
  - はかせは これに 加えて、ときどき ノートを のぞく/うなずく 程度の 小さな しぐさ 歓迎
- 切り替え: 歩行⇄待機は 0.2秒ほどで なめらかに ブレンド（急に止まらない）
- README に 周波数・振幅の定数を まとめ、調整箇所が分かるようにする
