## 1. 発注概要

スピノサウルス（MODEL I・採用済み）と同じ様式で、以下の7種を **1種ずつ順に** 納品する。

| 順 | 種 | 全長 | 区分 |

| 1 | ティラノサウルス | 12m | 第1章 |
| 2 | トリケラトプス | 8m | 第1章 |
| 3 | アンモナイト | 0.3m | 第1章（特例仕様 §4-3） |
| 4 | イグアノドン | 10m | 第1章の隠し種 |
| — | （ここで発注側レビュー。OK後に続行） | | |
| 5 | ブラキオサウルス | 23m | 第2章 |
| 6 | ステゴサウルス | 9m | 第2章 |
| 7 | アロサウルス | 8.5m | 第2章 |

- **1種 = 1コミット**（Conventional Commits。例: `feat(dino3d): tyrannosaurus model`）。
  各コミット時点でビルドが通り、ビューアーで確認できる状態にする
- 各種とも **骨格＋生体の2ビュー・同ポーズ**（06 §4 の契約どおり）

## 2. 共通仕様（第1弾からの追加・変更点）

1. **品質と作風の基準は MODEL I**（`src/art/dino3d/spinosaurus.ts`）。
   ロフトによる連続した有機ボリューム・滑らかな陰影・GeometryBatch によるdraw call削減、
   という作り方を踏襲する。`common.ts` のヘルパーを再利用し、必要なヘルパー追加は歓迎
   （ただし **スピノの見た目を変えない** こと）
2. **§10 の方針を全種に適用**: デフォルメは目・丸み・色にかける。二足／四足・脚の役割・
   姿勢という骨格構造は本書のシートどおりにし、変えない
3. **3案比較は不要。** 議論が分かれる要素は本書の各シートで発注側が裁定済み。
   シートを **拘束力のあるモデルシート** として扱い、完成判定の前に
   **真横の初期表示でシートの比率チェック項目を自己照合** する（§10-6/7 と同じ手順）
4. **登録**: 各種完成時に `src/art/dino3d/index.ts` の `BUILDERS` に1行追加する。
   これだけでゲーム本体の博物館展示（🏛️ てんじを みる）に自動で載る
5. **ビューアー**: `poc/poc9/` に **種セレクタ**（画面上部にボタン列など、48px以上）を
   追加してよい。カメラの目標点・距離は種ごとに調整してよい（アンモナイト0.3mと
   ブラキオ23mが同じカメラでは成立しないため）。URLは `?species=` パラメータ対応を推奨
6. **触ってよいファイル**: `src/art/dino3d/`（種ファイル追加・index.ts登録・common.ts拡張）
   と `poc/poc9/` のみ。**ゲーム本体（src/game/・src/ui/・src/main.ts等）は変更しない**
   （ゲーム内展示のカメラ自動フィット等は統合側= Claude が対応する）
7. 予算は従来どおり **1ビュー 10,000三角形以下・draw call 30以下**。
   スピノ実績（3.8〜4.8k / 3〜8dc）と同水準を目安にする
8. モジュール契約は種名を変えて同形:
   `export function buildTyrannosaurus(): DinoViews` など。座標系も同じ
   （1unit=1m・原点=足元の地面・顔は+X・実寸で作る。縮尺は呼び出し側）
9. 検証コマンドは 06 §6 と同じ。各種コミット前に build / ESLint / Prettier を通す

## 3. 全種共通の顔・表情ルール

- 目は大きめ・虹彩あり・ハイライト1点（MODEL I と同じ作り）。こわい顔にしない
- 歯や爪は「ある」と分かる最小限。ギザギザを強調しすぎない
- 肉食種も口は閉じ気味（威嚇ポーズにしない）

## 4. 種別モデルシート

### 4-1. ティラノサウルス（12m・二足）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | **水平姿勢の二足獣脚類**。背骨はほぼ水平、尾はまっすぐ後ろへ伸ばしてバランス。直立（ゴジラ立ち）にしない |
| あたま | **巨大で箱型の頭骨**が最大の見せ場。太いバナナ型の歯。首は短くS字 |
| うで | **とても小さく、指は2本**。地面につけない |
| あし | 太く長い後肢。3本指＋後ろに小さな1本 |
| 尾 | 太い付け根から先細り。地面につけない |

- 真横チェック: 頭が右／全長:全高 ≈ 2.6:1／頭骨は胴の半分近い大きさに見えてよい（こども頭身）／
  背骨水平・尾水平／腕が極端に小さいことが一目で分かる
- 骨格の読みどころ: 巨大頭骨と歯・**2本指の小さな腕**・太い後肢・肋骨かご
- 初期カラー: 体 `#9C6B43` ／ 腹 `#E8D9B0` ／ 背の縞 `#6E4A2E` ／ 虹彩 `#C68B38`

### 4-2. トリケラトプス（8m・四足）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | **正真正銘の四足**。前肢はやや外向きでどっしり。頭は低め |
| あたま | **目の上に長いツノ2本＋鼻先に短いツノ1本**。オウムのような**くちばし** |
| フリル | 首をおおう**大きな縁どり付きフリル**（本種最大の見せ場） |
| 胴 | 樽型でがっしり。尾は短め |

- 真横チェック: 頭が右／全長:全高 ≈ 2.7:1／フリルが背より高い最頂部／4本脚が同じ役割で接地
- 骨格の読みどころ: **フリルとツノは頭骨の一部**として連続していること・くちばし・
  どっしりした四肢帯
- 初期カラー: 体 `#7FA05A` ／ 腹 `#E9E2BC` ／ フリル縁の斑 `#D9A441` ／ ツノ `#F2EAD8`

### 4-3. アンモナイト（0.3m・特例仕様）

| 項目 | 指定 |
| --- | --- |
| 2ビューの意味 | **骨格ビュー＝殻の化石**（うずまき殻のみ、化石色）。**生体ビュー＝生きていた姿**（殻＋軟体） |
| 殻 | 平巻きのうずまき。**肋（放射状のすじ）**を浅く入れる |
| 軟体（生体のみ） | 殻の口から頭部＋**触腕10本前後**（先を丸く、こわくしない）。大きな目 |
| 化石殻（骨格ビュー） | 色は骨色系。**隔壁の縫合線**（うずまきに沿う細い線）を1〜2本の溝で示唆 |

- 真横チェック: うずまきの中心が見える向きが正面（+X は殻口側）／殻:軟体 ≈ 2:1
- 実寸 0.3m で作る（ビューアー側でカメラを寄せる。モデルを拡大して作らない）
- 初期カラー: 生体殻 `#DCC9A8`＋縞 `#A98F6B` ／ 軟体 `#E8907A` ／ 化石殻 `#F2EAD8` 系

### 4-4. イグアノドン（10m・二足寄り）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | **後肢で立つ二足姿勢**（四足歩行もできた種だが、展示は二足で立たせる）。背骨はやや前傾の水平 |
| て | **親指の大きなスパイク**（本種最大の見せ場）。指は5本で手のひらが分かる程度に簡潔に |
| あたま | 馬づらの長めの頭。くちばし状の口先 |
| 尾 | まっすぐ固く伸びる（下げない） |

- 真横チェック: 頭が右／全長:全高 ≈ 2.8:1／前肢は地面から離れる／**親指スパイクが
  シルエットでも読める**
- 骨格の読みどころ: **親指スパイク**・すだれ状の腱で固まった尾・くちばし
- 初期カラー: 体 `#8FA764` ／ 腹 `#EFE6C0` ／ 背の縞 `#6C8248` ／ スパイク `#F2EAD8`

### 4-5. ブラキオサウルス（23m・四足）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | 四足。**首を高く斜め上へ**伸ばす（キリンのように）。尾は太く短めで下がり気味 |
| 前後のバランス | **前肢が後肢より長く、肩が高い**（本種の決定的特徴。前後を逆にしない） |
| あたま | 小さい頭。**頭頂の丸いドーム（鼻の隆起）** |
| サイズ感 | 実寸23m。全高は12m前後になる |

- 真横チェック: 頭が右上／**肩が腰より高い**／首の長さ ≈ 胴の1.5倍以上／頭は小さく
- 骨格の読みどころ: 長い首椎の連なり・柱のような四肢・小さな頭骨
- 初期カラー: 体 `#7C8FB0` ／ 腹 `#E5DFC8` ／ 背 `#5F7191`

### 4-6. ステゴサウルス（9m・四足）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | 四足。**後肢が前肢より長く、腰が最頂部**（ブラキオと逆）。頭は低く地面近く |
| 板 | **背中に五角形の板が2列・互い違い**（本種最大の見せ場）。腰の上が最大 |
| 尾 | 先端に**長いとげ4本**（2対） |
| あたま | とても小さい頭 |

- 真横チェック: 頭が右下がり／板の並びが互い違いと分かる／腰が最頂部／尾のとげ4本
- 骨格の読みどころ: **板ととげは骨**として骨格ビューにも残す・小さな頭骨・高い腰
- 初期カラー: 体 `#A9793F` ／ 板 `#C9553F` ／ 腹 `#EBDFBB` ／ とげ `#F2EAD8`

### 4-7. アロサウルス（8.5m・二足）

| 項目 | 指定 |
| --- | --- |
| 姿勢 | 水平姿勢の二足獣脚類（ティラノと同系の立ち方） |
| ティラノとの見分け | **腕が長めで指3本＋かぎ爪**・頭はティラノよりほっそり・**目の上に小さなツノ状の隆起1対** |
| あたま | ほっそりした頭骨。目の上の隆起は色でも強調してよい |

- 真横チェック: 頭が右／全長:全高 ≈ 2.9:1／ティラノより頭が小さく腕が大きいと分かる
- 骨格の読みどころ: **目の上の隆起・3本指の腕**（=ティラノとの見分けが骨格でも読める）
- 初期カラー: 体 `#8C5A50` ／ 腹 `#E8D9B0` ／ 目の上の隆起 `#D9A441` ／ 虹彩 `#C68B38`
