# きょうりゅう はっくつ博物館（仮）ゲームデザイン仕様 v2.0（ドラフト）

> v1.0 からの大改訂。2026-08-19 のオーナーとの企画ブラッシュアップを反映し、
> 「フィールドで探す × 発掘で掘り出す」の二層構造に再設計した。
> **§0 の6原則はオーナー承認済み（確定）。§1 以降の詳細は本ドラフトのレビューで確定する。**
> v1.0 の内容のうち、恐竜リスト・復元パズル・子ども向け品質基準は原則そのまま引き継ぐ。

## 0. 設計原則（憲法・確定）

1. **主軸はコンプリート** — 12種（拡張で増える）の恐竜を全部よみがえらせることが目的。冒険も道具も博物館もこの主軸に奉仕する。経営・対戦・育成には広げない
2. **化石はうそをつかない（現実準拠）** — 化石は世界のどこかに最初から必ず眠っている。時間・日替わり・ランダムで湧かない・動かない・消えない。深いほど古い。見つかる場所の理屈も現実準拠（浸食で地層がむき出しになった崖・川岸・荒れ地に露出しやすい）。演出の着色は自由、地質と化石の根本ルールは曲げない
3. **二層構造** — フィールド＝探す（頭の勝負）× 発掘＝掘り出す（手の勝負）。両方に上達がある
4. **世界は変わらず、プレイヤーが成長する** — 進行とは「行ける場所が増える」（道具）と「手がかりが読める」（知識）こと
5. **学びは攻略に埋め込む** — 攻略に必要な知識がそのまま本物の古生物学の知識になる。教材パートを外付けしない
6. **拡張はデータパックで** — 新エリア＝新地層・新種・新掘り形式・新手がかりのセット。原則1〜5を満たす限り後から足せる

## 1. コンセプト

**「小さな島を たんけんして、12ひきの きょうりゅうを ぜんぶ よみがえらせよう」**

- ジャンル：探索 × 発掘 × コレクション（戦闘なし・経営なし・時間変化なし）
- ターゲット：小学校低〜中学年（6〜10歳）。未就学の弟妹は「歩く・掘る」だけでも遊べる
- 無料・広告なし・ログイン不要・GitHub Pages 配信（v1.0 から変更なし）

## 2. 世界：カセキ島（仮称）

ひとつの箱庭の島。徒歩2〜3分で横断できるサイズ。**化石の配置は固定の手作りマップ**（fossils/sites.json）。

| エリア | 露出する時代 | 見た目 | 解放条件 |
|---|---|---|---|
| すなの谷（スタート） | 白亜紀 | 明るい砂色の荒れ地・海岸 | 最初から |
| かぜの渓谷と大がけ | ジュラ紀 | 灰褐色の崖・川 | 復元3体 ＋ ロープ |
| あかの峡谷とどうくつ | 三畳紀 | 赤茶の岩・洞窟 | 復元6体 ＋ ランタン |

- 中央にベースキャンプ（はかせのテント）と博物館。ここが動線のハブ
- **エリア＝時代の理屈も現実準拠**：場所によって浸食・隆起でむき出しになっている地層の時代が違う（実際の恐竜化石産地と同じ理屈）。1つの発掘ブロックの中では従来どおり「深いほど古い」の表現を維持する
- v1.0 の「島の俯瞰マップからサイト選択」は廃止し、島そのものを歩く

## 3. 化石の眠り方（配置設計）

- **発掘ポイント＝「個体」**：1か所には同じ恐竜1個体の骨が2〜3個まとまって眠っている（現実の部分骨格・ボーンベッドと同じ）。1回の発掘で複数パーツが見つかるので、テンポも良くなる
- **各種2〜3個体**を島の別々の場所に配置。1個体では全パーツがそろわないことがある設計（基本線：**2か所掘って1体復元**）
- 初期リリースの発掘ポイント総数：**恐竜 約30〜36 ＋ おまけ（こはく・たまご・あしあと等）約10**。すべて固定・手作り配置
- **★の取り直し＝別個体**：雑に掘って傷ついた骨は傷ついたまま残る。きれいな★3が欲しければ、別の場所に眠る同じ種の個体を探して丁寧に掘る（「重複は★別に個数で貯まる」の既存決定と整合）
- 掘った現場（穴・削り跡）は世界に残る。埋め戻されたり復活したりしない

## 5. フィールド：探す

**移動・カメラ**
- **タップ移動**（行き先をタップ→キャラが歩く）。バーチャルスティックは使わない（6歳の確実性・3D酔い対策）
- カメラ：ゆるい見下ろしの追従。2本指ドラッグで回転・ピンチでズーム（角度・距離制限）
- **ワープ**：一度訪れた「看板」へは地図からひとっ飛び（島は狭いが、往復のダルさを消す）

**手がかりは3層**
1. **目で見つける**：露出した骨のかけら・地表のひび・崖の縞模様の乱れ。近づくと「！」が出て調べられる
2. **話と記録**：はかせの話、現場の看板、島に落ちている「たんけん日記」の切れはし（「かわの まがりかどの がけに おおきな ホネを みた」）
3. **知識で絞る**：図鑑の時代情報 →「ジュラ紀のアロサウルスなら、かぜの渓谷だ」

**発見の流れ**：手がかり地点を調べる →「ここに なにか ねむってる！」→ 発掘ポイントとして地図に記録される → 掘る（すぐでも後でもよい）

**道具ゲート**（メトロイドヴァニア式・最小構成）
- **ロープ**：崖を降りられる → ジュラ紀エリアと壁掘り現場へ
- **ランタン**：洞窟に入れる → 三畳紀エリアへ
- 入手は進行報酬（復元数）＋はかせのイベント。実在の発掘道具である点も柱5に沿う

**げんき（体力）**
- フィールド移動では消費しない（探索は自由）。発掘でのみ消費
- キャンプ（テント）で全回復。ペナルティは「戻る手間」だけ

## 6. 発掘：掘り出す（POC-2 v2 をベースに確定）

**共通ルール（POC-2 で検証済み）**
- ピッケル（速い・広い・骨に当てるとヒビ）／ブラシ（遅い・安全）
- げんきゲージ、化石接近ヒント（音＋キラキラ）、ヒビ→★3/★2/★1
- げんき切れ：現場はそのまま残る（穴も傷も）。キャンプで休んで再挑戦

**エリア＝掘り形式**（同じ操作系で、盤面のルールが変わる）
| エリア | 形式 | 新ルール |
|---|---|---|
| すなの谷 | 基本ボクセル（上から） | なし（操作を覚える） |
| 大がけ | **壁掘り（横から）** | かたい岩セル（ピッケル2回・ブラシ不可）→ ルート選び |
| どうくつ | 上から＋**くずれる砂** | 削ると上のセルが落ちる → 手順パズル。ランタンの明かりの範囲だけ見える |

**大物発掘（クライマックス）**
- 最後の1体（ブラキオサウルス級）は島の最奥の巨大現場。1回では掘りきれず数回通う。全長比較演出につなげる

## 7. よみがえらせる：復元・図鑑・博物館

- **復元ラボ**：v1.0 どおりガイド付き骨格パズル（設定でガイドOFF）。**とくちょうパーツをはめた瞬間に恐竜の名前が判明する演出**（「おおきなあご…ティラノサウルスだ！」）— 同定＝学びの山場
- **図鑑**：名前（ルビ）／時代／食性／全長（人間・スクールバス3D比較）／ひとこと学び／**どこで見つけたか（島の地図にピン）**／化石状態★
- **博物館**：トロフィールーム。復元すると自動で展示され、台座のポーズ選択くらいの軽い自己表現のみ（経営要素なし）。★3は金の台座。来館者NPCは復元数で増える「にぎわい演出」に留める
- 12種コンプ：かんちょうトロフィー＋感謝演出（v1.0 踏襲）。コンプ後のご褒美「ナイトミュージアム」（夜、骨格がこっそり動く）は検討枠

## 8. 進行の背骨

1. **導入10分**：浜辺に露出した骨（チュートリアル現場）→ 初発掘 → 初復元 → 博物館に1体 → はかせ「この島には まだまだ ねむっているぞ」
2. **中盤**：すなの谷の個体を探して復元3体 → ロープ入手 → 渓谷へ（壁掘り解禁）→ 復元6体 → ランタン → 峡谷・洞窟へ
3. **はかせランク**：発掘数と★で「みならい → ほりだし名人 → でんせつのはかせ」。初期は称号＋はかせの話が増える程度に軽く
4. **終盤**：12種目＝大物発掘イベント → コンプリート

## 9. 学びの埋め込み（柱5の実装点）

| 遊びの仕組み | そのまま学びになる知識 |
|---|---|
| 深く掘るほど古い層 | 地層累重の法則 |
| 崖・川岸・荒れ地で見つかる | 浸食が化石を露出させる（実際の化石産地の理屈） |
| 1か所に骨がまとまって眠る | 部分骨格・ボーンベッド |
| とくちょうパーツで名前が判明 | 種の特徴（かむ力・ツノ・帆…） |
| ロープ・ランタン・ハケ | 実際の発掘調査の道具 |

- 言葉にする場所：はかせのひとこと・層またぎ演出・図鑑。テスト形式にはしない

## 10. データ設計への影響（柱6）

- `areas.json`（エリア・解放条件・掘り形式）／ `sites.json`（**固定の発掘ポイント配置**：場所・個体＝種と骨の内訳・深さ・手がかり）／ `dinosaurs.json`（v1.0 踏襲）／ `tools.json` ／ はかせのセリフ・日記テキスト
- **拡張パック＝新エリア一式**（地形＋地層＋新種＋掘り形式＋手がかり）。コードを触らず追加できること

## 11. スコープ外（初期リリース）

- v1.0 の項目（クラウド・マルチ・読み上げ・多言語・写真）に加えて：
- 経営・集客・通貨システム／時間帯や天候の変化／戦闘・ミニゲームバトル／ペット育成
- **拡張候補（入れない が構造は用意）**：相棒の犬（においで化石を探す・拡張1号候補）／たんちき（地中レーダー。実在道具なので柱2適合）／氷・琥珀みがきの掘り形式／ナイトミュージアム

## 12. 成功基準（改訂）

- 6歳がチュートリアルなしで「最初の化石を見つける→掘る→復元」まで到達できる
- 子どもが「どこを掘ればいいか」を自分の言葉で説明できる（手がかり設計が機能している証拠）
- iPad Safari 30fps以上（目標60）／初回ロード15秒以内（フィールド追加後も維持）
- 12種の通しプレイが可能

- 性能予算：フィールドシーンが最重量になる見込み。ローポリ箱庭＋遅延ロードで v1.0 の予算（15万トライアングル・DPR≤2）を維持する
