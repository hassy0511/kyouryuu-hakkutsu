# POC-1 結果レポート：iPad Safari 描画性能

- 実施日: 2026-08-19
- 判定: **合格（GO）** — 60fps 基準「文句なし合格」
- 確認 URL: https://hassy0511.github.io/kyouryuu-hakkutsu/poc/poc1/

## 検証構成

- ダミー発掘シーン: 地形＋ボクセル 8×8×6（InstancedMesh 384個・層ごとの色）＋恐竜1体（アニメ再生）＋AmbientLight＋DirectionalLight（シャドウマップ 1024px）
- シーン負荷: 三角形 20,724 / ドローコール 22 / JS gzip 約141KB
- 恐竜は開発環境からアセット配布サイトへ到達できなかったため、実素材 glb と同等負荷のコード生成スキンメッシュ（約1.2万トライアングル・ボーン10本・AnimationMixer）で代替。**実素材の検証は POC-3 で行う**

## 計測結果（オーナー実機 iPad / Safari）

| 項目 | 結果 |
|---|---|
| FPS | **約60**（かげ ON・がしつ 2.0x の初期設定のまま） |
| メモリ警告・クラッシュ | 報告なし |
| その他の問題 | 報告なし |
| 参考: 初回表示 | 開発環境計測で約1秒（Wi-Fi 15秒以内の予算に対し余裕） |

## 判断

- 合格基準（60fps → 文句なし合格）を満たしたため、**Three.js を確定**。Babylon.js 比較検証は実施しない
- シャドウ 1024px・devicePixelRatio 2.0 でも余裕があるが、本実装ではシーンが重くなるため性能予算（02_TECH_SPEC §5）は引き続き遵守する
